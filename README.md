## Armstrong Level 4 – Week 14

This repository contains multiple small Node.js/Express topics organized by sections (`section1`, `section2`, `section3`) plus a larger `weekly-project`.

- **Prerequisites**: Node.js (v18+ recommended) and npm installed.
- **Install dependencies**: Run `npm install` inside each topic folder before running it the first time.
- **Run a topic**: From that topic folder, use `node index.js` or `npm start` (if a start script exists in `package.json`).

### Folders

- **section1**: Topic exercises 1.2, 1.3, 1.4
- **section2**: Topic exercises 2.2, 2.3, 2.4, 2.5
- **section3**: Topic exercises 3.2, 3.3
- **weekly-project**: Main weekly project (Express API with auth, products, orders, payments, etc.)
